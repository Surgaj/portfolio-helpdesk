# portfolio-helpdesk
Portfólio com práticas de suporte técnico, formatação, acesso remoto e troubleshooting para atuação em Help Desk / Suporte TI.

## 👨‍💻 Sobre
Repositório com práticas e procedimentos utilizados em suporte técnico, manutenção de computadores e atendimento remoto. 
Experiência prática adquirida através de atuação profissional e estudos em Análise e Desenvolvimento de Sistemas.

---

## 🛠️ Atividades Técnicas
- Formatação e instalação de Windows
- Instalação e atualização de drivers
- Configuração básica de redes
- Manutenção preventiva de hardware
- Suporte técnico ao usuário
- Acesso remoto utilizando AnyDesk e TeamViewer
- Instalação de softwares corporativos

---

## 📋 Troubleshooting (Problemas Comuns)
- Lentidão no sistema operacional
- Falhas de inicialização do Windows
- Problemas de conexão de rede
- Erros de aplicativos
- Configuração de impressoras

---

## 🌐 Ferramentas Utilizadas
- Windows 10 / 11
- AnyDesk
- TeamViewer
- Pacote Office
- Noções básicas de Java
- Redes básicas
